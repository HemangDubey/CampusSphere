keydown vs keyup (and keypress)

  • keydown fires when a key is pressed, and repeatedly while it is held (repeat becomes true). Use it for shortcuts and games.
  • keyup fires once when the key is released. Use it when you need to know a key is no longer held.
  • keypress is deprecated. It only fired for keys that produce characters and is inconsistent across browsers. Use keydown with event.key instead. It is shown above only so you can see it is legacy.
  • event.key is the character or key name ("a", "Enter"); event.code is the physical key ("KeyA"), the same on every keyboard layout.
