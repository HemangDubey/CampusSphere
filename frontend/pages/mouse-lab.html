Mouse events

Interact with each zone to see which event fires and what information the browser gives you. Only the latest event is shown, so nothing floods the page.

Touchscreens: mouse events are designed for a pointer. Phones and tablets simulate some of them (a tap usually produces mouseover, mousedown, mouseup and click) but hover, right-click and mousemove do not behave the same. Each demo has a keyboard button that dispatches a simulated event so you can still see the idea.

mouseenter vs mouseover, mouseleave vs mouseout

Move the pointer into the outer box, then into the inner box and back. mouseenter/mouseleave fire only for the element itself. mouseover/mouseout also fire when the pointer moves between the element and its children (they bubble).
